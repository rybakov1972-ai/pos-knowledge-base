## Ближний горизонт (инкрементальное, 1–2 года)

### 1. [5 — позиционные районы / гражданская защита] Минпросвещения: алгоритмы для школ при угрозе БпЛА
- **Источник:** [ГАРАНТ — текст рекомендаций](https://base.garant.ru/414756507/) (по состоянию на 14.08.2026, опубликовано в базе 09.09.2026); региональная практика — [Улпресса, 22.10.2026](https://ulpressa.ru/2026/10/22/bez-siren-rezhim-povyshennoj-gotovnosti-utochnili-instrukczii-dlya-shkol-pri-raketnoj-i-bespilotnoj-ugrozah/).
- **Суть:** единого федерального акта об оповещении о беспилотной опасности нет — порядок задают регионы; чаще всего два уровня («беспилотная опасность» — укрытие не требуется; «угроза атаки БпЛА» — укрыться); алгоритмы расписаны по ролям (педагог, администрация, техперсонал, ответственный за укрытие), обязательная сверка наличия, выход из укрытия только по команде руководителя. В Ульяновске 15.10 часть директоров действовала не по инструкции, родители получили противоречивые указания; региональное министерство пояснило, что СМС без сирен — информационный сигнал, а не команда.
- **Что это меняет для нас:** модель пансиона получает нормативную опору: две ступени сигнала, роли и «сверка наличия» становятся обязательными элементами сценария 100 дней. Для кемпа — готовая основа для ролей и разбора: «где алгоритм сломался у людей, а не у техники».
- **Статус:** Первоисточник (текст рекомендаций в ГАРАНТ) + Пересказ (региональная практика в СМИ). Пункт вне окна 1–3 дня, но в базе его не было.
- **Условие начала действия:** сразу — сверка модели пансиона (Р-1); для кемпа — после согласования Игорем, что гражданские алгоритмы входят в материалы кемпа 1.
- **L3-модуль:** Civil_Protection, Simulation_Training.

### 4. [5 — позиционные районы] «Коммерсантъ»: первоисточник по рекомендациям Минцифры для ЦОД
- **Источник:** [«Коммерсантъ», 25.10.2026](https://www.kommersant.ru/doc/9060109).
- **Суть:** документ есть у редакции; Минцифры подтвердило, что рекомендации разосланы профильным организациям. Критически важные ЦОД делятся на три категории: К1 (сбой ключевых государственных функций от часа), К2 (региональные и отраслевые системы, от четырёх часов), К3 (корпоративные). Опрошенные участники рынка ждут роста цен на услуги примерно на 10%, оценка дополнительных затрат на объект — 5–10%.
- **Что это меняет для нас:** появляется готовый образец категорирования объекта по последствиям простоя — его можно перенести на пансион (что важнее: укрытие, связь, питание, медпункт). Экономика «плюс 5–10% к стоимости объекта» — ориентир для кемпа 2.
- **Статус:** Первоисточник (публикация со ссылкой на документ и подтверждением министерства); сам текст рекомендаций не опубликован — цифры удорожания — оценки участников рынка.
- **Условие начала действия:** сразу — черновик категорирования пансиона (Р-4); использовать на кемпе 2, где появляется экономика.
- **L3-модуль:** Civil_Protection, Economic_Model.
