# L1 — Raw Data

Сырьё: карточки компаний, контракты, PDF, сводки, доктрины.

## Правила записи

- **Append-only.** Записи не редактируются и не удаляются.
- **Ошибка фиксируется новой записью**, которая ссылается на ошибочную (`supersedes: <id>`), а не правкой старой.
- **У каждой записи есть источник и дата**: URL/ссылка на документ и дата получения. Нет источника — нет записи.
- Каждая запись указывает связанный модуль L3.
- Непроверенное помечается статусом `[НЕ ВЕРИФИЦИРОВАНО]`.
- L1 не правит L2 напрямую: изменения в структуре — только через патч онтологии.

## Структура

| Папка | Что кладём |
|---|---|
| `companies/` | Карточки компаний |
| `contracts/` | Контракты, тендеры, закупки |
| `documents/` | PDF и другие первичные документы |
| `daily_digest/` | Ежедневная сводка DefenseTech (пишется только в L1) |
| `doctrines/` | Доктрины, уставы, ROE |

Шаблон записи: [`_TEMPLATE.md`](_TEMPLATE.md). Имя файла: `YYYY-MM-DD_<краткий-id>.md`.
