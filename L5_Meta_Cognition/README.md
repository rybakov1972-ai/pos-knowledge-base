# L5 — Meta-Cognition Layer

Пример реализации процедуры порождения нового слоя (манифест, раздел 4).
L5 не отвечает на вопросы о дронах. Он отвечает на вопрос **«почему наша модель перестала предсказывать»** — класс задач, недоступный агентам L4, у которых контракт привязан к предметной области.

## Контракт слоя (4 условия)

### 1. Класс задач, не решаемый существующими агентами

Вопрос: «Почему прогнозы модели (L2 + агенты L4) расходятся с наблюдаемой реальностью и какие правила/допущения устарели?»
Ни один агент L4 не может ответить на него в рамках своего контракта: их контракты — о предметной области, а не о самой модели.

### 2. Контракт входа/выхода

- **Вход:** записи `Explainability_Log.md`; открытые вопросы `Model_Health.md`; история версий онтологии (`L2_Structured_Knowledge/ontology/CHANGELOG.md`); новые записи L1, противоречащие L2; результаты `L4_Thinking_Layer/simulation/`.
- **Выход:** диагностический отчёт (markdown): симптом расхождения → гипотеза причины → затронутые допущения/классы онтологии → предлагаемый патч онтологии или изменение контракта агента.
- **Качество:** доля диагнозов, после применения которых расхождение устранено в следующем цикле; [метрика уточняется].

### 3. Протокол обратной записи

- **В L1:** сам диагностический отчёт как новая append-only запись (тип `document`).
- **В L2:** только через патч онтологии ([`ONTOLOGY_PATCH_TEMPLATE.md`](../L2_Structured_Knowledge/ONTOLOGY_PATCH_TEMPLATE.md)) после валидации.
- **В Model_Health:** обновление статуса затронутых открытых вопросов.

### 4. Владелец

**Владелец:** _не назначен_ (человек или агент, отвечающий за жизненный цикл слоя).
