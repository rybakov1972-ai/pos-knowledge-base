## Выводы и гипотезы

- Перехватчики ~70% против «Шахедов», мобильные группы до 40% (Сырский) — оценки спорны (MH-020).
- Расход: 3 на цель (dev.ua) до 5–10 (Касьянов) → глубина запаса важнее цены единицы.
- Собственное изделие — только как эталон для протокола (концепция 18.10); развилки MH-006/MH-008.
