# L3 — Research Modules

Исследования по направлениям.

## Правила

- **Расширяемый по определению:** новая папка = новое направление. Направление появляется как папка, а не как согласование.
- Новый модуль создаётся копированием [`_MODULE_TEMPLATE/`](_MODULE_TEMPLATE/).
- **Пустые направления архивируются в [`_archive/`](_archive/), но никогда не удаляются.**
- Находки модуля опираются на L1; изменения структуры знаний — через патч онтологии в L2.
- Раз в цикл — ревизия: какие модули пусты (см. `governance/CYCLE_REVIEW_TEMPLATE.md`).
