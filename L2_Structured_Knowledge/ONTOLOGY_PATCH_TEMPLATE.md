# Шаблон патча онтологии

Не спорьте с онтологией в переписке — оформите патч (issue «Патч онтологии» или PR).

## Порядок

1. Скопируйте текущую версию `ontology/vN/` в `ontology/vN+1/`.
2. Внесите изменения в новую версию; старую не трогайте.
3. Заполните описание ниже и добавьте строку в `ontology/CHANGELOG.md`.
4. Валидация: человек + агент-валидатор. После одобрения новая версия становится текущей.
