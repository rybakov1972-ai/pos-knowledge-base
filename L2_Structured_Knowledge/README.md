# L2 — Structured Knowledge

Онтология, граф знаний, реестры, таксономии.

## Правила

- **Каждая правка = новая версия онтологии** (`ontology/v1` → `ontology/v2`). Предыдущие версии не удаляются; изменение описывается в [`ontology/CHANGELOG.md`](ontology/CHANGELOG.md).
- **Любое утверждение имеет ссылку на артефакт L1.** Нет ссылки — нет утверждения.
- **Непроверенное помечается явно:** `[НЕ ВЕРИФИЦИРОВАНО]`, а не замалчивается.
- Противоречия не удаляются — фиксируются в [`../Model_Health.md`](../Model_Health.md).
- Артефакты L4 попадают в L2 только после валидации.
- Изменения предлагаются через [`ONTOLOGY_PATCH_TEMPLATE.md`](ONTOLOGY_PATCH_TEMPLATE.md), а не в переписке.

## Структура

| Папка | Назначение |
|---|---|
| `ontology/` | Версии онтологии и журнал изменений |
| `knowledge_graph/` | Граф знаний (сущности и связи) |
| `taxonomies/` | Таксономии и классификаторы |
| `registries/` | Указатель на реестры: сами реестры лежат в корневой папке [`../Registries/`](../Registries/), логически это часть L2 |
