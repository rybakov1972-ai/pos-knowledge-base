# Registries — реестры

Реестры вынесены в корень репозитория для удобства навигации, но **логически являются частью L2 Structured Knowledge** и подчиняются его правилам:

- каждое утверждение — со ссылкой на артефакт L1 (`L1_Raw_Data/...`);
- непроверенное помечается `[НЕ ВЕРИФИЦИРОВАНО]`;
- существенные правки (новые колонки, переклассификация) проходят через патч онтологии и фиксируются в `L2_Structured_Knowledge/ontology/CHANGELOG.md`.
